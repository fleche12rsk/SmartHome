Política de privacidade

Atualizada em 3 de novembro de 2026.

Resumo

O Casa não tem conta, servidor próprio, anúncios nem estatísticas de uso. Ele não coleta, vende nem compartilha dados.

O que fica no seu aparelho

O endereço do seu Home Assistant e o token de acesso ficam guardados apenas no armazenamento local do navegador do aparelho em que você os digitou. Eles nunca são enviados para nós nem para terceiros. Para apagar, use “Desconectar” em Ajustes ou limpe os dados do site no navegador.

Com quem o painel conversa

O painel se conecta somente ao Home Assistant que você informar, para ler o estado dos aparelhos e enviar os comandos que você tocar. As imagens das câmeras vêm direto do seu Home Assistant.

Hospedagem

Os arquivos do site são servidos pelo GitHub Pages. Como qualquer servidor, o GitHub pode registrar dados técnicos de acesso, como o endereço IP, conforme a política de privacidade do GitHub.

Cookies

O site não usa cookies. A instalação na tela de início guarda uma cópia dos arquivos do painel no aparelho para abrir mais rápido.

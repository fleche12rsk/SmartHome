# Casa

Versões prontas do **Casa**, um painel de casa inteligente para celular, tablet e navegador.

- **Site e painel web:** https://fleche12rsk.github.io/SmartHome/
- **APK para Android:** aba [Releases](https://github.com/fleche12rsk/SmartHome/releases). O app instalado
  confere esta página sozinho e avisa quando há versão nova.

Este repositório só recebe os arquivos prontos (APK e site). Nenhuma senha, token ou configuração de
casa fica aqui: cada pessoa conecta os próprios aparelhos dentro do app.
